# Portable optional voxel diffuse GI

`helengine_gi` is an independent C++17 static library. It has no Core, camera, window-system, graphics-API, Gevo, or configurable engine-number dependency. Its numeric boundary is explicitly IEEE-754 32-bit float, matching RGBA32F GPU data. Compile without fast math. This implementation is a bounded dense grid, not a sparse octree.

## Submission and lifetime

Construct `helgi::VoxelGi` with explicit `Config` bounds, dimensions and ray count. Submit world-space, linear-albedo triangles with `SetContributor(id, revision, triangles)`. Geometry is copied. The winding defines the single-sided reflecting normal; all occupied voxels block visibility from either side. An identity/revision pair must always describe the same payload, including after removal/reinsertion. Repeating the current revision performs no work. Each contributor retains independent coverage, so removing overlapping geometry cannot erase another contributor.

Call `SetSun` with a nonzero direction **toward** the sun and nonnegative incident normal irradiance. Direction and color/intensity changes invalidate lighting. Direct-shadow rendering can remain disabled: the solver always performs its own sun visibility and bounce visibility.

`BeginUpdate` snapshots pending geometry and sun. `AdvanceUpdate(maxWorkItems)` also starts work when idle and processes a finite number of candidate tests, retained intersections, cell illuminations or integration rays. Each DDA ray has at most `CountX + CountY + CountZ + 3` steps. At most six visibility rays occur in one illumination work item. Allocation/snapshot initialization is bounded by the validated volume but occurs when starting a generation. There is no time-deadline guarantee; choose a work budget appropriate to the host.

Edits submitted during a solve are coalesced for the **next** solve; they do not restart the in-flight generation. A completed, possibly older snapshot publishes atomically at a call boundary, preventing continuous motion from starving publication. `Field.Generation`, `Stats.InputGeneration` and `Stats.UpdatePending` expose this asynchronous lag. Calls are single-threaded: applications must serialize submission, update and sampling. `GetField` references remain valid until the next publication; copy/upload the atlas before advancing again.

No input change means no SAT tests, no radiance solve and no publication. Sun-only edits reuse all cached coverage. Geometry edits voxelize only changed contributor revisions. Aggregate cell occupancy/material data is rebuilt from retained independent intersections (one intersection per work unit), which avoids subtractive drift and preserves overlaps. Lighting is recomputed for the complete snapshot because visibility changes can affect distant cells. This is one diffuse bounce; atlas irradiance is never fed back as another emitter.

Invalid inputs throw. Fixed limits are 1..128 cells per axis, 262144 total cells, 1..256 rays/lobe, 65536 submitted triangles, 16777216 candidate tests per snapshot and 4194304 retained triangle-cell intersections. World coordinate magnitudes must not exceed 1e6; voxel sizes must be at least 1e-4 and at least four float ULPs at the volume's coordinate scale. Albedo is [0,1], sun irradiance [0,1e6]. Degenerate triangles, zero normals/directions and nonfinite values throw. Candidate/coverage overrun throws during staging, discards that private stage, and retains the last valid published field. Correct or remove the offending input before retrying. Required configuration values are never substituted.

## Transport and atlas contract

The full 13-axis triangle/box SAT tests the clipped candidate range conservatively, including touching voxel boundaries; it does not fill the triangle's AABB. Per cell, intersecting surfaces are area-weighted into six dominant-normal groups. Sun-visible groups emit `L = albedo * sunIrradiance * max(dot(normal,toSun),0) / pi`. Voxel DDA occludes both sunlight and first-hit reflected radiance. Cosine-distributed deterministic hemisphere samples integrate irradiance with `pi / RaysPerLobe` weights, rather than multiplying by cosine twice. Six directional irradiance lobes approximate arbitrary receiver normals; positive cardinal normal components are normalized by their sum. This is deliberately low-frequency diffuse transport.

The atlas is row-major RGBA32F, with width `CountX * CountY` and height `CountZ * 6`. Cell `(x,y,z)` and lobe `l` occupy pixel `(x + CountX*y, z + CountZ*l)`. Lobes are `+X,-X,+Y,-Y,+Z,-Z`. Empty-probe RGB stores linear **irradiance**. Alpha is 1 for valid empty probes, 0 for uniformly coplanar occupied cells, and -1 for occupied cells containing mixed planes. Uniform occupied cells carry plane metadata instead of irradiance: lobe 0 RGB is the unit plane normal, canonicalized so its dominant absolute component is positive (X, then Y, then Z breaks ties); lobe 1 R is the matching signed plane offset `dot(normal, triangle.A)`. Other occupied RGB is unused and zero. Mixed cells have no usable plane metadata. Empty scenes and rays leaving the bounds contribute zero; the sun is never an ambient term. A renderer shades a diffuse receiver with `receiverAlbedo * sampledIrradiance / pi`, applying exposure/tone mapping afterward.

Grid cell centers are `Minimum + (coordinate + 0.5) * voxelSize`. Surface positions must be moved outward along the geometric normal far enough to leave conservative occupied coverage before probing (typically about one voxel; thin features and diagonal surfaces may need more). `SampleIrradiance` returns zero outside the volume and for probes inside opaque cells. It performs trilinear filtering with occupied taps removed and query-to-tap DDA visibility, then renormalizes surviving weights. A GPU consumer must implement the same occupancy-aware filtering; ordinary hardware trilinear filtering can cross walls. Reject every alpha-nonpositive tap **and** occupied cells along each query-to-tap segment. A receiver may leave conservative surface coverage only when its actual position lies on the initial uniform plane and every occupied cell traversed during exit has the same metadata plane within the solar plane tolerances. A different plane or any mixed cell must stop that exit; skipping contiguous occupancy can tunnel through a separate roof. The atlas contains all six copies of the same occupancy mask for this purpose. Do not interpolate across lobe boundaries or apply an ambient fallback.

Thin walls are deliberately conservative opaque coverage and may occupy adjacent cells. Finite voxels can close sub-voxel openings, merge nearby surfaces, lose surface detail, and produce visible temporal lag at high resolution. Increase spatial resolution or enlarge openings for faithful transport; these trade-offs are explicit rather than hidden ambient light. Deterministic rays may show low-sample directional error.

## Build and verification

Configure this directory with CMake and build `helengine_gi_tests`; `ctest` runs the portable tests. The tests exercise triangle/AABB false positives, conservative boundary coverage, colored bounce, a sun-blocking roof versus an opening, reflected-light blockage by a vertical wall versus a window, overlap removal, moved geometry, sun-only coverage reuse, unchanged revisions, staged publication, input coalescing, invalid bounds/normals, finite values and camera-independent world samples.

On the development Windows machine, GCC `-O2 -fno-fast-math` measured a 32x24x32 grid with 8 rays/lobe, six floor/roof triangles and an aperture: 4096 work items/call took 257 calls, 152 ms total CPU and 2.35 ms maximum observed call; 8192 took 129 calls, 135 ms total and 1.74 ms maximum observed call. Warm-up/scheduling differ; these are observations, not frame-time guarantees. At one call per 60 Hz frame, 129 calls imply about 2.15 seconds publication latency. Debug builds and other hardware require their own measurements.

MSVC Debug (/Od /Zi /RTC1 /MDd /fp:precise) on the same scene measured 724.6 ms total, 11.95 ms maximum call at budget 4096, and 726.1 ms total, 17.40 ms maximum call at budget 8192. Startup allocation is included. The 8192 Debug budget can exceed a 60 Hz frame, even though release observations were much lower.

The CMake MSVC **Debug GI kernel is intentionally optimized** with `/O2 /Zi /fp:precise`, while preserving `/MDd` and therefore the embedding Debug runtime ABI. Directory-local Debug flags remove incompatible `/RTC*` checks and `/Od`/`/Ob0`; this does not modify the parent's variables/cache or other engine targets. Debugger stepping through the kernel may reorder or omit optimized locals. A real Visual Studio CMake Debug build passed CTest (1/1); its generated project confirms `MaxSpeed`, `ProgramDatabase`, `MultiThreadedDebugDLL`, `Precise`, and no runtime checks. The same CMake-built benchmark measured 156.4 ms total / 2.44 ms maximum call at 4096 units, and 155.8 ms / 5.19 ms at 8192. Scheduler variance explains why maximum call times need host measurements. Set `HELENGINE_GI_BENCHMARKS=ON` to build `helengine_gi_benchmark` and repeat these observations.

Solar visibility retains each intersecting triangle's actual plane. The source location is the voxel center projected onto that plane, avoiding false shadows from neighboring floor coverage under grazing sunlight. A solar DDA ray can bypass an occupied cell only when every triangle in that cell is coplanar with the source plane, including reversed winding. Normal components must agree within eight float epsilons; plane offsets use two scaled float epsilons plus one-millionth of the smallest voxel size. Different parallel planes, tilted planes, walls, and mixed-geometry cells remain blockers. Mixed-plane source voxels conservatively emit no solar reflected radiance, so edges where several surfaces merge can be darker at coarse resolution. Bounce rays and probe-filter visibility still treat every occupied cell as opaque. Regression tests compare the unobstructed grazing/vertical floor irradiance ratio with the analytic cosine, verify a real wall blocks that grazing source, and verify a distinct parallel roof suppresses it without treating the roof as source coverage.
